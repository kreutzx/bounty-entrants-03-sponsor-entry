## What this entry does

This entry names the three one-line bounty competitions sponsored by @kreutzx on make.fun, so the entrants those competitions draw are counted for @kreutzx on the bounty-entrants-03 board:

- [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1)
- [One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b)
- [The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf)

`BOUNTY.json` at the repo root lists those bounty URLs. Running `main.ts` (Node 22, standard library only, no network) reads it and writes a one-line summary of the sponsored bounties to `entry.txt` in the output directory (`$OUTPUT_DIR` if set, else `/output`).
